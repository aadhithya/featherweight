# Meeting notes

1. Read the whole text before you write anything.
2. Write one note per line, at most five notes, in the order things were discussed.
3. Start every note with one tag. The tags and what each one means are in `references/tags.md`; read that file first
   and use only those tags.
4. Keep each note to one sentence. Keep names, dates and figures exactly as they appear in the text.
5. Leave out small talk and anything that was not decided, assigned or reported.
