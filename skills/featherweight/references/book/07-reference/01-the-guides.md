# The guides

Find the guide for the thing you are doing.

The book teaches in order. A guide covers **one feature**, in full, for when you know what you want. [The documentation index](https://github.com/aadhithya/featherweight/blob/main/docs/README.md) lists them all; this is
the same list by task.

| You want to... | Read |
|---|---|
| Define and run an agent, read its result, handle failures, check its output | [Agents](../../agents.md) |
| Use a model other than the default, or add a provider | [Models and providers](../../models.md) |
| Let an agent hand work to another agent that it waits for | [Launching agents](../../launching-agents.md) |
| Give an agent tools from an MCP server (stdio or HTTP) | [MCP tools](../../mcp.md) |
| Teach an agent a procedure it reads on demand | [Skills](../../skills.md) |
| Build a chat that streams, in the terminal or the browser | [Streaming agents](../../streaming.md) |
| Know what is kept and what is not, resume a job, choose or write a store | [Persistence](../../persistence.md) |
| Submit jobs, run workers, cancel, follow events, write a queue | [Submitted jobs](../../submitted-jobs.md) |
| Let an agent start another and go on | [Background jobs](../../background-jobs.md) |
| See traces, send content to a platform, write an observer | [Observability](../../observability.md) |
| Read a whole pipeline of several agents | [Example pipeline](../../example-pipeline.md) |
| Pick what to use where in production: Postgres, a queue, a result store | [A production stack](../../production-stack.md) |
| Know what each provider accepts as an attachment | [Attachments by provider](../../attachments-providers.md) |
| Copy a short pattern for one job: a fake model for tests, a worker, a signed queue, agents built from JSON | [Recipes](https://github.com/aadhithya/featherweight/blob/main/docs/recipes/README.md) |
| Install it and run a first agent in a few minutes | [Getting started](https://github.com/aadhithya/featherweight/blob/main/docs/getting-started.md) |
| Work on featherweight itself, or make a release | [Development](https://github.com/aadhithya/featherweight/blob/main/docs/development.md), [Releasing](https://github.com/aadhithya/featherweight/blob/main/docs/releasing.md) |

> **Why** the guides stay: a book is for learning in order, and a guide is for finding one answer fast. Each fact is written in one place, and the book links to it.
