# The featherweight book

Build something with featherweight, step by step. A short chapter at a time, you grow one small project, an incident report assistant, from
a single typed agent to a chat and a pipeline on workers. Read it in order, or jump in through [the map](00-start-here/02-the-map.md).

New to featherweight? Start with [what it is](00-start-here/01-what-it-is.md). Writing a chapter? See [the style](STYLE.md).
